Blog Motoru ve Dinamik Veri Fihristi

BTÜ Geçerken blog altyapısı; tek bir JavaScript veri modelinden (blog.js) beslenen, arama ve filtrelemeyi istemci tarafında (Client-Side) yürüten, ancak her makaleyi bağımsız bir statik HTML sayfası olarak sunan hibrit bir mimariye sahiptir.

Neden Bağımsız HTML Dosyaları? Arama motoru optimizasyonu (SEO), sosyal medya önizlemeleri (Open Graph meta etiketleri) ve akademik atıf kalıcılığı için her makale kendine ait fiziksel bir .html dosyasına sahiptir. blog.js ise bu makalelerin yalnızca dizinini (metadata) tutarak arşiv ve arama motoru işlevi görür.

1. Veri Şeması (blog.js)

Her makale nesnesi aşağıdaki katı tip yapısına uygun olarak blogPosts dizisine kaydedilir:

const blogPosts = [
  {
    id: 34,                                      // Benzersiz tamsayı kimliği
    title: "İslam Metaetiği: İyi-Kötü Ayrımı Nasıl Kurulur?", // Tam başlık
    cat: "İslam Felsefesi",                      // Filtreleme kategorisi
    date: "7 Ağustos 2026",                      // Yayınlanma tarihi
    readTime: "18-22 dk okuma",                  // Tahmini okuma süresi
    excerpt: "İslam düşüncesinde ahlaki eylemler nasıl değerlendirilir?...", // Kart özeti
    img: "islam-metaetigi.jpg",                  // Kapak görseli dosya adı
    link: "islam-metaetigi.html"                 // Hedef fiziksel HTML rotası
  }
];

2. İstemci Taraflı Sayfalama ve Arama Algoritması

Blog motoru (btugecerkenblog.html) yüklendiğinde şu işlem basamaklarını çalıştırır:

  • Filtreleme Hattı: Seçili kategori (örn: "Sanat Tarihi" veya "Hepsi") ve arama kutusuna yazılan anahtar kelime aynı anda değerlendirilir. Arama işlemi hem title hem de excerpt üzerinde küçük/büyük harf duyarsız (case-insensitive) regex ile taranır.
  • Sayfalama Hesabı: Sayfa başına 12 makale (postsPerPage = 12) sınırıyla toplam sayfa sayısı dinamik hesaplanır: 
    const totalPages = Math.ceil(filteredPosts.length / postsPerPage);
const startIndex = (currentPage - 1) * postsPerPage;
const paginatedItems = filteredPosts.slice(startIndex, startIndex + postsPerPage);
  • DOM Enjeksiyonu: Yalnızca o sayfaya ait 12 kartlık HTML şablonu oluşturulup #blogGrid konteynerine basılır. Bu sayede yüzlerce makale olsa dahi tarayıcı render performansı düşmez.

Etkinlik Arşivi ve Takvim Panosu Mimarisi

Topluluğun kurulduğu günden bu yana gerçekleştirdiği tüm paneller, atölyeler, geziler ve hasbihal programları etkinlikler.js veri tabanı üzerinden arşivlenir.

1. Etkinlik Veri Modeli

const events = [
  {
    id: 38,
    title: "Medeniyet ve Şehir Söyleşileri",
    academicYear: "2026/2027",                  // Dönem filtresi anahtarı
    category: "Seminer & Panel",
    date: "14 Kasım 2026",                      // Etkinlik tarihi
    time: "14:30",
    location: "Mimar Sinan Yerleşkesi A Blok",  // Konum bilgisi
    desc: "Bursa'nın kadim mimarisi üzerine...", // Tanıtım metni
    tags: ["mimari", "tarih", "bursa"],         // Canlı arama etiketleri
    link: "etkinlik-detay-38.html",             // Detay veya kayıt sayfası
    isUpcoming: true                            // Yaklaşan etkinlik durumu
  }
];

2. Akademik Dönem Taksonomisi

Etkinlikler üniversite takvimine paralel olarak akademik dönemlere göre indekslenir:

  • 2026/2027: Aktif akademik yıl etkinlikleri.
  • 2025/2026: Geçmiş dönem arşivi.
  • 2024/2025: Kuruluş yılı faaliyetleri ve saha projeleri.

3. Modal Takvim Panosu ve Faaliyet Çizelgesi

Sayfada yer alan yüzen takvim butonu, arka planı karartarak etkileşimli bir takvim penceresi açar:

  • Yaklaşan Programlar Bölümü: isUpcoming: true bayrağına sahip etkinlikleri otomatik olarak üst şeride çeker.
  • Yıllık Faaliyet PDF İndirme: Topluluğun üniversite Sağlık, Kültür ve Spor Daire Başkanlığı'na (SKSDB) sunduğu resmi faaliyet planını tek tıkla indirilebilir formatta sunar.

Merkezi Dinamik Footer Motoru

Ekosistem genelinde yer alan onlarca bağımsız blog ve etkinlik sayfasında navigasyon menülerinin, yasal uyarı linklerinin ve sosyal medya bağlantılarının tek bir merkezden yönetilmesi için dinamik enjeksiyon algoritması geliştirilmiştir.

Sıfır Ek Dosya İlkesi: Sayfaların açılışında ekstra bir HTTP isteği oluşturmamak adına footer motoru bağımsız bir footer.js yerine, tüm sayfalarda zaten yüklü olan çekirdek script.js içerisine yerleştirilmiştir.

1. Dizin ve Kök Yol Çözümleme Algoritması (basePath)

Fiziksel sayfalar kimi zaman ana dizinde (/index.html), kimi zaman alt kategorilerde bulunabilir. Bağlantıların kırılmasını önlemek için script şu mantıkla dinamik ön ek üretir:

// URL yolundaki klasör derinliğini ölçer
const isSubFolder = window.location.pathname.split("/").filter(Boolean).length > 1;
const basePath = isSubFolder ? "/" : "";

// Üretilen link örneği:
// Kök dizinde: "dergilik.html"
// Alt dizinde: "/dergilik.html"

2. Hedef Yakalama ve Enjeksiyon

Motor sayfa yüklendiğinde DOM üzerinde sırasıyla #footer-placeholder id'li veya footer.site-footer sınıflı elementi arar; bulduğunda kurumsal marka sütununu, ekosistem alt alan adlarını (Farabi AI, Docs, Lab) ve iletişim bloklarını dinamik olarak enjekte eder:

<!-- Sayfa geliştiricisinin tek yazması gereken HTML satırı: -->
<footer class="site-footer" id="footer-placeholder"></footer>
<script src="navbar.js" defer></script>
<script src="script.js" defer></script>

Topluluk Organizasyonu ve Birimler

BTÜ Geçerken Topluluğu; akademik, kültürel ve teknik üretimi sürdürebilmek adına modüler ve iş bölümüne dayalı bir teşkilat yapısıyla yönetilir.

1. Yönetim Kurulu

  • Topluluk Başkanı: Üniversite yönetimi, SKSDB ve dış paydaşlarla resmi koordinasyon; topluluk vizyonunun korunması.
  • Başkan Yardımcıları: Birimler arası senkronizasyon, haftalık planlama ve idari takip.

2. İhtisas Ekipleri

  • Proje ve Ar-Ge Ekibi: Web platformlarının (btugecerken, Farabi AI, Docs, Lab) geliştirilmesi, Nginx/Linux sunucu yönetimi, Dify yapay zekâ entegrasyonları ve akademik araştırma projeleri.
  • Sosyal Medya ve Tanıtım Ekibi: Dijital mecralar için görsel/video tasarımı, etkinlik duyuruları, YouTube kanal yönetimi ve kitle iletişimi.
  • Organizasyon ve Lojistik Ekibi: Konferans salonu koordinasyonu, kampüs izinleri, ikram ve saha etkinliklerinin icrası.
  • Yayın ve Editör Ekibi: Dergilik sayıları (Mahya, Culture), blog tahlil yazıları ve yayın kurulunun yönetimi.
