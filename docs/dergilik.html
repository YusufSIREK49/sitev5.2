Dergilik Kataloğu ve URL Parametre Protokolü

BTÜ Geçerken Dergilik platformu (dergilik.html); topluluğun akademik, kültürel ve sanatsal süreli yayınlarını sergileyen dijital kütüphane vitrinidir.

Tek Sayfa - Çoklu Yayın Prensibi: Her dergi sayısı için ayrı ayrı HTML sayfaları üretilmez. Sistemde yalnızca tek bir okuyucu arayüzü (pdf-viewer.html) bulunur; açılmak istenen derginin dosya yolu ve başlığı URL arama parametreleri (Query Parameters) ile okuyucuya aktarılır.

1. Yayın Veritabanı Şeması (dergilik.js)

Yayınlanan her sayı magazineDatabase dizisine aşağıdaki nesne formatıyla kaydedilir:

const magazineDatabase = [
  {
    id: "culture-1",
    title: "BTÜ Geçerken Culture - Sayı 1",
    series: "BTÜ Geçerken Culture",       // Seri grubu (Culture, Mahya, Account Originals)
    issue: "Sayı 1",
    date: "Ekim 2026",
    period: "Her Ayın 15'i",               // Yayın periyodu
    desc: "Mitoloji, İlk Yerleşimler, Blokzincir ve Empresyonizm dosyaları...",
    cover: "BTU_Gecerken_Culture_1.png",  // Kapak görseli
    pdfUrl: "BTU_Gecerken_Culture_1.pdf", // Sunucudaki fiziksel PDF dosyası
    badge: "YENİ YAYIN",                  // Vitrin rozeti
    featured: true                         // Öne çıkan ana vitrin yayını
  }
];

2. Okuyucu Başlatma Protokolü

Kullanıcı dergilik sayfasında bir derginin "Hemen Oku" butonuna bastığında tarayıcı şu URL yapısını üretir:

pdf-viewer.html?file=BTU_Gecerken_Culture_1.pdf&title=BTÜ%20Geçerken%20Culture%20-%20Sayı%201

pdf-viewer.js motoru sayfa açıldığı anda window.location.search parametrelerini çözümler, üst başlığı günceller ve belirtilen PDF dosyasını asenkron olarak indirmeye başlar.

İnteraktif Okuyucu, Çift Tuval ve Notlu PDF Derleme

pdf-viewer.js, basit bir PDF görüntüleyicisinden öte; tablet, telefon (dokunmatik) ve grafik tablet (stylus) uyumlu, tarayıcı içi çalışan eksiksiz bir dijital not alma motorudur.

1. Çift Tuval Mimarisi (Dual Canvas Pattern)

Çizimlerin orijinal PDF metinlerini ve vektörlerini bozmasını engellemek amacıyla iki katmanlı tuval hiyerarşisi uygulanmıştır:

+-------------------------------------------------------------+
|  ÜST KATMAN: #drawCanvas (HTML5 Canvas - Şeffaf Zemin)     |  <-- Kullanıcının Kalem/Silgi Çizimleri
+-------------------------------------------------------------+
|  ALT KATMAN: #pdfCanvas  (PDF.js Tarafından Render Edilen)  |  <-- Orijinal Vektörel PDF Sayfası
+-------------------------------------------------------------+
  • Alt Tuval (#pdfCanvas): Mozilla'nın açık kaynak pdf.js kütüphanesi tarafından ilgili sayfanın yüksek DPI (Device Pixel Ratio) ile çizildiği salt-okunur katmandır.
  • Üst Tuval (#drawCanvas): Kullanıcının serbest el çizimlerini, işaretlemelerini ve fosforlu vurgularını yakalayan şeffaf etkileşim katmanıdır.

2. Fırça Modları ve Kompozisyon Algoritmaları

Tuval çizim motoru üç farklı araç moduna sahiptir:

  • Tükenmez Kalem: globalCompositeOperation = 'source-over' modunda, kullanıcının seçtiği renk ve kalınlıkta opak vektörel çizgiler çizer.
  • Fosforlu Kalem (Highlighter): Yarı saydam alfa kanalı (rgba(r, g, b, 0.4)) ve source-over kompozisyonu ile metinlerin üzerini kapatmadan altındaki yazının okunmasını sağlar.
  • Piksel Silgisi: globalCompositeOperation = 'destination-out' modu ile PDF sayfasına dokunmadan yalnızca üstteki çizim katmanının piksellerini saydamlaştırır.

3. Sayfa Geçiş Önbelleği (drawingCache)

Kullanıcı sayfalar arasında ileri/geri gezinirken çizimlerin silinmesini önlemek için bellek içi önbellekleme uygulanır:

// Sayfadan ayrılırken mevcut çizimi kaydet:
function saveCurrentPageDrawing() {
  drawingCache[currentPageNum] = drawCanvas.toDataURL('image/png');
}

// Yeni sayfaya geçildiğinde varsa eski çizimi tuvale geri bas:
function restorePageDrawing(pageNum) {
  if (drawingCache[pageNum]) {
    const img = new Image();
    img.onload = () => drawCtx.drawImage(img, 0, 0);
    img.src = drawingCache[pageNum];
  }
}

4. PDF-Lib ile Çizimleri Birleştirip İndirme (Export Pipeline)

Kullanıcı "Çizimlerle İndir" butonuna bastığında hiçbir sunucu işlemi gerekmez; işlem tamamen kullanıcının tarayıcısında (Client-Side) gerçekleşir:

  1. Orijinal PDF'in ham baytları (ArrayBuffer) pdf-lib kütüphanesine yüklenir.
  2. drawingCache taranır; kullanıcının çizim yaptığı her sayfa için PNG verisi pdfDoc.embedPng() ile PDF nesnesine gömülür.
  3. Gömülen çizim katmanı ilgili PDF sayfasının üzerine tam sayfa boyutunda bindirilir.
  4. Derlenen yeni PDF dosyası Blob formatına dönüştürülüp kullanıcının cihazına otomatik olarak indirilir.
