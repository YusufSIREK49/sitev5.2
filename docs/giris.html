Ekosistem Vizyonu ve Mimari Topoloji

BTÜ Geçerken; Bursa Teknik Üniversitesi bünyesinde ilmi, kültürel, akademik ve teknolojik üretimleri tek bir çatı altında birleştiren bağımsız bir dijital ekosistemdir.

Temel Mimari İlke: Sistem; bakım maliyeti yüksek ilişkisel veritabanları (RDBMS) veya hantal monolitik CMS katmanları yerine; modern Vanilla JavaScript modülleri, bağımsız fiziksel HTML sayfaları, Nginx ters vekilleri (Reverse Proxy) ve Docker tabanlı Dify LLM servisleri ile mikro mimaride, yüksek hız ve tam izolasyon prensibiyle inşa edilmiştir.

2. Kritik Nginx Yönlendirme Kuralları (lab.btugecerken.com)

          
A. Uzantısız Temiz URL Çözümlemesi ($uri $uri.html)

          
Kullanıcıların veya arama motorlarının /resizer yazdığında arka planda resizer.html dosyasına yönlendirilmesi için Nginx kuralı:

          
location / {
    root /var/www/lab;
    index index.html;
    try_files $uri $uri.html $uri/ /index.html;
}


          
B. Statik Dosyaların Döngüden Korunması

          
location ~* \.(pdf|png|jpg|jpeg|gif|ico|webp|svg|css|js|woff|woff2)$ {
    root /var/www/btugecerken;
    access_log off;
    expires 7d;
    add_header Cache-Control "public, max-age=604800";
    try_files $uri =404;
}


          
C. Nginx Düzeyinde API Yetkilendirme (Reverse Proxy)

          
location /api/dify/ {
    proxy_pass https://ai.btugecerken.com/v1/;
    proxy_ssl_server_name on;
    proxy_set_header Host ai.btugecerken.com;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Authorization "Bearer YOUR_DIFY_APP_KEY";
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 120s;
}


          
D. FastAPI Backend Reverse Proxy (Port 8001)

          
Büyük video ve ağır PDF aktarımlarında zaman aşımı olmaması için client_max_body_size 250M ve 600 saniyelik okuma tamponu tanımlanmıştır:

          
location /api/ {
    proxy_pass http://127.0.0.1:8001;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 250M;
    proxy_read_timeout 600s;
    proxy_connect_timeout 600s;
    proxy_send_timeout 600s;
    proxy_buffering off;
}
